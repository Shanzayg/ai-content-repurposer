# AI Content Repurposer

Turn YouTube links and PDFs into tweets, blogs, and clips using AI agents.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Local Setup

1. Copy `.env.example` to `.env.local`
2. Add your API keys
3. Run:

cd app
npm install
npm run dev
